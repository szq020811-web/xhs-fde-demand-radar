# 小红书 FDE 需求雷达

一套用于发现、筛选和分级小红书企业 AI 落地需求的 Codex Skill。

它不会只搜索“FDE”这个词，还会覆盖企业 AI 转型、Agent 开发、私有化部署、AI 项目交付、业务流程改造等真实需求表达，并结合正文和公开评论判断需求意向。

## 主要能力

- 五层 FDE 需求关键词库
- 企业 AI 落地场景扩展
- 正文与公开评论联合分析
- 需求线索自动评分
- A、B、C、D 四级线索分类
- 招聘、培训、社群和服务商广告降权
- 支持行业、地区、时间和业务场景筛选
- 输出原帖链接、意向证据与风险说明

## 五层关键词体系

1. 直接需求词：找 AI 团队、寻找 AI 服务商、Agent 开发外包等
2. 企业问题词：企业 AI 转型、AI 项目落地难、老系统接入 AI 等
3. 业务场景词：AI 销售、智能客服、企业知识库、AI 质检等
4. FDE 同义词：前线部署工程师、AI 驻场团队、大模型交付工程师等
5. 强意向词：预算、报价、立项、采购、私有化、交付、上线等

完整关键词见：

[`references/keyword-library.md`](references/keyword-library.md)

## 线索等级

| 等级 | 含义 |
|---|---|
| A级 | 明确寻找团队或服务商，并具有预算、立项、周期等实质信号 |
| B级 | 企业问题和业务场景明确，但尚未明确采购 |
| C级 | 行业案例、市场讨论或需求洞察 |
| D级 | 招聘、广告、培训、泛科普或低相关内容 |
